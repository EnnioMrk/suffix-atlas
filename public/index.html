What the scan does

Suffix Atlas looks for one word in the public suffix space: the endings in the IANA root zone, plus a set of common multi-level registries such as co.uk and com.au.

Coverage

The scan tests 1,900 candidate names: one name per suffix. It does not search page content or find subdomains such as maps.google.com. A public suffix is not a website. A name enters the results when it resolves; the tabs separate those that answer from those that do not.

Direct

Direct means the HTTPS endpoint for the apex name answers with a 2xx status and no redirect. The HTTPS request is sent once, and redirects are never followed to turn a redirect into a direct result.

Wildcards

If a random label under a suffix also resolves, the suffix answers every name. The scanner marks it as a wildcard and skips it, so it cannot appear in every search.

Reachable and redirects

Reachable means the server answered any HTTP status. A normal redirect from the apex to www is reported as live after redirect, not as direct. Redirects to another site are labelled redirects away.

Limits

Some sites block automated requests with 403 or 429 responses. Those names are reachable but not direct. The probe uses public IPv4 addresses; an IPv6-only site can show no answer. DNS and web responses change; a scan records a moment, not a permanent state. Results are held in memory and are not saved.
